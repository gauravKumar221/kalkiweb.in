# **App Name**: KalkiWeb Bold

## Core Features:

- Home Hero: Hero section with headline, sub-text, and CTAs.
- Services Overview: Display services in a grid layout with cards and a 'Get Proposal' CTA for each service.
- Portfolio Showcase: Portfolio section showcasing client projects, with project cards and a 'View Project' link for each.
- Careers Section: Display current job openings in cards with title, location, and type.
- Contact Form: Implement a contact form for users to send messages and inquiries.
- AI Illustrations: Incorporate tool that the application can use to produce illustrations/icons to complement features.
- UI Components: Sticky Navbar with black background and yellow hover, plus footer with quick links and newsletter signup.

## Style Guidelines:

- Primary color: Yellow (#FACC15) for main elements, buttons, and highlights to create a bold and energetic feel.
- Secondary color: Black (#0A0A0A) for backgrounds, text, and important UI elements to add a premium and creative touch.
- Accent color: White/Gray (#F0F0F0) for secondary text and background accents, providing contrast and readability.
- Headings font: 'Inter' sans-serif for a modern and clean look (Note: currently only Google Fonts are supported.)
- Body font: 'Inter' sans-serif for a clear and readable text (Note: currently only Google Fonts are supported.)
- Lucide-react icons for a consistent and modern visual style.
- Responsive layout with mobile-first approach, ensuring a seamless experience across all devices.
- Framer Motion for subtle animations like fade, slide-in, and hover lift to enhance user engagement.
